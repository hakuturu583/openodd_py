# openodd-editor

An editor for ASAM OpenODD 1.0 YAML in the browser: Rust, [Leptos](https://leptos.dev)
and WebAssembly, checked as it is edited by openodd's own reader. Its *Fuzzy
rules* mode edits a backend's rule files as forms. See
[docs/editor.md](../../docs/editor.md).

```bash
trunk serve            # from this directory
```
